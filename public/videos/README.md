# Sample UGC Video Assets Directory

Place your 9:16 vertical `.mp4` video files inside this directory (`/public/videos/`) using these filenames:

- `skincare-ad.mp4` — Project 1: Skincare UGC Ad (Minimalist Vitamin C 10% Face Serum)
- `perfume-ad.mp4` — Project 2: Perfume UGC Ad (CHANEL COCO MADEMOISELLE Eau de Parfum Intense)
- `whey-protein-ad.mp4` — Project 3: Whey Protein UGC Ad (Optimum Nutrition Gold Standard 100% Whey)
- `fashion-ad.mp4` — Project 4: Fashion UGC Ad (Velmora red midi dress)

You can also customize all video paths, poster paths, titles, and descriptions in `/src/data/portfolioData.ts`.
